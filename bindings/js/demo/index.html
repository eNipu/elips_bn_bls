Verification runs one multi-pairing over all the public keys at once, not one per signer.

Nothing leaves this tab. The keys, the signatures and the pairing check are all computed here, in WebAssembly. There are no network requests after the page loads — the module is embedded in it. Open your browser's network panel and watch.

This is slower than the native library, by a lot. wasm32 has no 64×64 → 128 bit multiply, so every field multiplication goes through a software helper, and one pairing is tens of thousands of them. Measured on the same machine:

nativewasm
sign1.77 ms7.41 ms
verify3.43 ms18.56 ms

Not audited. This implements draft-irtf-cfrg-bls-signature on BLS12-381 and agrees with an independent implementation on every build. That is not the same thing as having been reviewed by a cryptographer, and it should not be used to protect anything that matters yet.

Source and the library it is built on: eNipu/elips_bn_bls.
